# AbleMark Web

Веб-редактор этикеток и печать на Bluetooth термопринтерах прямо из браузера. Протокол
печати восстановлен методом обратной разработки из Android-приложения **AbleMark**
(`com.feioou.deliprint.ablemark`).

Никакого нативного приложения, драйверов и плагинов — открываете страницу в Chrome/Edge,
выбираете BLE-принтер и печатаете этикетки.

**[English version](README.md)**

## Возможности

- **Десктопный редактор** — канвас со свободным перетаскиванием, ручками выделения,
  поворотом, масштабированием, списком слоёв, выравниванием и горячими клавишами.
- **Типы элементов**: текст, дата/время, штрихкод (Code 128), QR-код (в т.ч. пресеты
  Wi-Fi / визитка / ссылка), изображение, линия, фигура, таблица, серийный номер, цена.
- **Профили моделей** — принтер определяется по имени, автоматически подбираются протокол,
  направление печати, DPI и размер бумаги (L-серия, P50/S2, D100/X4 и др.).
- **Настройки печати** — тип бумаги (наклейка с промежутком / непрерывная / чёрная метка),
  плотность, копии, направление, качество отрисовки (порог или Floyd–Steinberg).
- **Инкрементальная печать** — серийные номера и инкремент штрихкода на каждой копии.
- **Информация об устройстве** — заряд батареи, остаток бумаги, версия прошивки, серийный
  номер, MAC-адрес, автоотключение (чтение/запись), статус.
- **Сервисная панель** — калибровка, калибровка промежутка, звук, экран вкл/выкл,
  синхронизация времени, прогон до метки, индукционная печать, сброс к заводским.
- **BT-консоль** — отправка произвольных hex-команд с просмотром сырых ответов (удобно для
  исследования принтера).
- **Шаблоны** — сохранение в `localStorage`, применение, экспорт/импорт `.amlbl` (JSON).
- **Двуязычный интерфейс** — русский и английский.
- **WYSIWYG-предпросмотр** — показывает ровно тот 1-битный растр, что уйдёт на печать
  (суперсэмплинг + box-фильтр для чётких краёв текста).

## Поддерживаемые принтеры

Любой принтер с протоколом AbleMark / yxqapp SDK поверх **BLE**:

| Серия | Модели | Протокол |
|---|---|---|
| L-серия | P11, P12, P15, P7, P1s, M1, S15, S12, A1, LP15, LP90, LPC74, YEW12 | `l` |
| P50-семейство | P50, P5OS, P50S, T2, M50, M57, S2, X2, M60, ET-Z05xx, Jammuk | `p50` |
| P80 | P80, P80S, T3 | `l` |
| D-серия | D100, D200, X4, L100, U210 | `p50` |
| Чеки | ESC/POS-совместимые (58/80 мм) | `escpos` |

> Принтеры только с Bluetooth Classic **SPP** (например D100/D200/S8) из браузера не
> подключаются — Web Bluetooth даёт доступ только к GATT (BLE).

## Требования

- **Chrome, Edge или Opera** (десктоп или Android) с поддержкой **Web Bluetooth**.
- Страница должна быть открыта по **HTTPS** (или `http://localhost`) — Web Bluetooth
  требует [secure context](https://developer.mozilla.org/ru/docs/Web/Security/Secure_Contexts).
- BLE-принтер, не подключённый к другому устройству (принтер держит одно соединение).

## Быстрый старт

### Локально

```bash
# отдайте корень репозитория любым статическим сервером, например:
python -m http.server 8000
# или
npx serve .
```

Откройте <http://localhost:8000>, нажмите **Подключить**, выберите принтер, добавьте
элементы слева, настройте свойства справа и нажмите **Печать**.

### GitHub Pages

Запушьте в `main` — встроенный workflow (`.github/workflows/deploy.yml`) развернёт сайт на
GitHub Pages автоматически. Затем включите Pages в настройках репозитория:

**Settings → Pages → Source: GitHub Actions**.

## Разработка и тесты

```bash
node test/protocol.test.js    # команды, кодеки, парсеры, поворот, серийники
node test/templates.test.js   # библиотека шаблонов
node test/i18n.test.js        # полнота словарей RU/EN
node test/ascii.test.js       # чёткость растеризации (нужен Chrome)
node test/smoke.test.js       # сквозной UI-тест (нужен Chrome, puppeteer-core)
```

Тесты `smoke`/`ascii` требуют `puppeteer-core` и локальный Chrome; при необходимости
поправьте путь к исполняемому файлу в тесте.

## Как это работает

Приложение рисует этикетку на canvas, преобразует в 1-битный растр (суперсэмплинг +
box-фильтр или Floyd–Steinberg), при необходимости поворачивает по направлению печати
модели и отправляет байты на принтер по BLE с кредитным управлением потоком.

Полная документация протокола: [`docs/PROTOCOL.md`](docs/PROTOCOL.md) и
[`docs/BT_OPERATIONS.md`](docs/BT_OPERATIONS.md).

## Ограничения

- Нет Bluetooth Classic **SPP** (ограничение браузера).
- Нет обновления прошивки / OTA (требует нативных кодеков и boot-режима).
- Нет кодека JBIG (X8/D100 используют нативную библиотеку).
- Шаблоны со встроенными изображениями не сохраняются между сессиями (картинки хранятся
  только в памяти).
